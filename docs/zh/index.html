GITVIZ · 原生 MACOS 应用

看清每次提交，
读懂分支之间的关系。

Gitviz 是一个独立的 macOS Git 图形客户端。浏览提交历史、分支和标签，行内展开提交详情，查看代码与图片差异，并快速切换仓库。

下载 macOS 版 ↓在 GitHub 查看源码 ↗

v0.1.0 · macOS 13 及以上 · Apple Silicon 与 Intel 通用版本

主要功能

  • 彩色提交关系图，同时展示本地分支、远程分支与 tag。
  • 行内查看提交信息、父提交和文件树；点击文件打开大幅 diff。
  • 在文本 diff 中搜索、多行选中和复制，预览图片的修改前后版本。
  • 使用 ⌘P 按名称切换仓库，支持 VS Code .code-workspace 工作区。
  • 检查远程分支和 tag 是否更新，显示当前分支的 ahead/behind 状态。
  • 可选切换仓库自动 Fetch，支持明暗主题与上次仓库恢复。

安装方式

下载 ZIP、解压，然后将 gitviz.app 拖入 Applications。系统需要已安装 Git；没有 Git 时，可运行 xcode-select --install 安装 Apple 命令行工具。

当前版本使用本机临时签名，尚未经过 Apple 公证。首次启动可能需要在“系统设置 → 隐私与安全性”中选择“仍要打开”。完整安装与校验说明（英文）。

Fetch 不会自动 Pull

自动 Fetch 更新远程引用与 tag，不会自动合并代码，也不会替你切换本地分支。本地分支是否落后仍会单独显示。

项目与源码

本仓库是使用 Go 和 MyGo 构建的实现，与 Rust 版 Gitviz 独立维护。Gitviz 不是 VS Code 扩展，也不声称与 VS Code Git Graph 完全功能一致。
