START HERE

A few steps.
A clearer history.

Install Gitviz on macOS, open a repository, and explore its Git graph.

Requirements

  • macOS 13 or later.
  • An Apple Silicon or Intel Mac. The download is a universal app.
  • Git installed and available on your system.

If Git is not installed, install Apple’s Command Line Tools:

xcode-select --install

1. Download and install

Download Gitviz for macOS, open the ZIP, and drag gitviz.app to your Applications folder.

The current version is 0.1.0. Release notes and previous versions are available on GitHub.

2. Allow the app on first launch

The current download is ad-hoc signed. It is not notarized by Apple, so macOS may block the first launch.

  1. Try opening Gitviz from Applications.
  2. Open System Settings → Privacy & Security.
  3. Find the blocked-app message and choose Open Anyway, if available.
  4. Confirm the system prompt, then open Gitviz again.

Only proceed with a download you trust. For current system instructions, see Apple’s guide to opening apps safely.

3. Open a repository or workspace

Use Open Repository in the app, or open a VS Code .code-workspace file to load its repositories. Press ⌘P to find and switch repositories by name. On the next launch, Gitviz restores the last opened repository.

You can also launch it from Terminal:

open -a /Applications/gitviz.app --args /path/to/repository

Verify the download

Download SHA256SUMS.txt from the same release as the ZIP. In the folder containing both files, run:

shasum -a 256 -c SHA256SUMS.txt

The result should be Gitviz-macOS-universal.zip: OK. The checksum checks that the file matches the published asset; it is not a substitute for Apple notarization.

Build from source

Use macOS, Git and Go 1.27.3 or later. The MyGo dependency is pinned in go.mod.

git clone https://github.com/senwong/gitviz-mygo.git
cd gitviz-mygo
./script/build
./build/gitviz-mygo /path/to/repository

Run ./script/package for an app for the current architecture, or ./script/release for the universal macOS ZIP.

Remote authentication and settings

Gitviz uses your installed Git executable and existing authentication. If a remote operation fails, verify that the same Git command works in Terminal. App settings are stored in ~/.config/gitviz-mygo/.

If you need help, open an issue with your macOS version, Gitviz version and the error message. Do not include credentials or private repository data.
