Gitviz and
VS Code Git Graph.

Gitviz is for people who want to explore a Git graph in a standalone macOS application. It takes inspiration from the Git Graph workflow while providing its own native desktop interface.

Choose the workspace that fits you

VS Code Git Graph is an extension used inside Visual Studio Code. Gitviz is an independent desktop app; it does not require VS Code to be open.

If your Git workflow is already centered on your editor, the extension may be the right fit. If you want a separate window for repository history and diffs across projects, try Gitviz.

What will feel familiar?

  • Colored branch lanes and commit nodes.
  • Branch and tag labels alongside commit messages.
  • Commit details with parent links and changed files.
  • Context menus for Git operations.
  • Finding commits by message, author, SHA or reference.

What does Gitviz offer as a desktop app?

  • Its own native macOS window and keyboard shortcuts.
  • A repository picker and support for VS Code workspace files.
  • Full-size text diffs with search and multiline copy.
  • Before/after previews for supported images.
  • Remote branch/tag freshness checks and optional Fetch on repository changes.

Independent projects

Gitviz is not affiliated with or endorsed by the maintainers of VS Code Git Graph or Microsoft. It does not claim complete feature parity with the extension. Refer to each project’s documentation for its current behavior.
