A FEW THINGS TO KNOW

Before you open it.

What is Gitviz?

Gitviz is a native Git graph viewer and desktop Git client for macOS. It helps you explore commit history, branches and tags, inspect changes, and work across repositories.

Is it a VS Code extension?

No. Gitviz is a standalone desktop application. Its workflow is inspired by VS Code Git Graph, but it is a separate project with its own implementation.

Does switching repositories pull or change my local branch?

No. With automatic Fetch enabled, switching repositories refreshes remote refs and tags. It does not pull, merge or check out a different branch. Those are separate actions.
