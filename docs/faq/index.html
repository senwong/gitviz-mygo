GOOD QUESTIONS

A little more
about Gitviz.

The practical details before you start exploring.

What is Gitviz?

Gitviz is a native Git graph viewer and desktop Git client for macOS. It helps you explore commit history, branches and tags, inspect changes, and work across repositories.

Is it a VS Code extension?

No. Gitviz is a standalone desktop application. Its workflow is inspired by VS Code Git Graph, but it is a separate project with its own implementation.

Does switching repositories pull or change my local branch?

No. With automatic Fetch enabled, switching repositories refreshes remote refs and tags. It does not pull, merge or check out a different branch. Those are separate actions.

Can I compare images?

Yes. Gitviz reads supported raster images from the selected Git revisions and shows before/after previews. Supported formats include PNG, JPEG, GIF (first frame), WebP, BMP and TIFF. A text-diff view remains available; preview limits apply to large images.

Does it support Apple Silicon and Intel Macs?

Yes. The universal macOS download contains both arm64 and x86_64 binaries. It requires macOS 13 or later and an installed Git executable.

Why does macOS ask me to allow the app?

The current release is ad-hoc signed and is not notarized by Apple. After trying to open it, you may need to allow it in System Settings → Privacy & Security → Open Anyway. See the installation guide for details.

Does Gitviz need a GitHub account?

A GitHub account is not required for local Git repositories. Remote operations use your installed Git and its existing authentication configuration, whether your remotes are on GitHub or another Git server.

Can I use it on Windows or Linux?

This project currently distributes and verifies the macOS application. Windows and Linux releases are not currently provided.
