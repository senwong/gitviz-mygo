THE GITVIZ WORKSPACE

A Git graph.
With the details.

Explore repository history, then move directly into the changes that matter. Gitviz keeps graph navigation, commit details and file diffs close together.

01

History, connected.

Follow colored branch lanes and merge paths. See local branches, remote branches and tags together in a readable Git graph.

02

The details stay with you.

Expand a commit inside the graph to read its message, parents and changed files. Open a file for a larger diff, then return with ⌘W.

03

Every kind of change.

Find text in code diffs and copy across lines. For supported images, compare the versions stored in Git side by side.

04

All your repositories.

Switch projects with ⌘P, search by repository name, or open the repositories in a VS Code .code-workspace file.

05

Remote status, in view.

Check for remote branch and tag changes, inspect ahead/behind counts, and optionally Fetch on repository switches. Fetch does not pull or merge.

06

A native place to work.

A standalone Go desktop application built with MyGo, with light and dark themes, visible shortcuts and last-repository restore.

Read a commit in context

Click a commit to expand its message, author, parents and changed files inside the graph. Click it again to collapse. Selecting a commit does not intentionally scroll it to the top.

Give the diff some room

Click a file to open a larger diff. Use ⌘F to find text, ⌘G to move between matches, and drag across lines to copy code with its spaces and line breaks. Use ⌘W or Back to Git Graph to return.

Compare image versions

Supported PNG, JPEG, GIF, WebP, BMP and TIFF files open in a before/after preview. Gitviz reads committed images from Git blobs, not from the current working copy. Added and deleted images show the available side. GIF previews show the first frame.

To keep memory use bounded, previews are limited to 32 MiB and 40 megapixels per image. Unsupported or damaged data, including unavailable Git LFS content, displays a fallback message. The raw text diff remains available.

Understand remote freshness

A local ahead/behind count compares cached refs. Gitviz can separately check configured remotes for branch and tag changes. The footer distinguishes unchecked, checking, current, fetch-needed and failed states, and records the check time. A successful check becomes stale after five minutes; it is not a continuous guarantee.

Automatic Fetch can run when switching repositories. After a successful automatic Fetch and graph reload, the graph scrolls to the top. Fetch does not pull or merge remote commits into the checked-out branch.

Work with branches, commits and tags

Context menus provide operations such as checkout, branch and tag creation, merge, rebase, cherry-pick and revert. Available actions depend on the selected reference and repository state. Gitviz uses your installed Git and existing credentials for remote operations.

Keyboard shortcuts

Choose a repository
⌘⇧P
Open the command palette
⌘B
Choose a branch filter
⌘F
Find in the graph or current text diff
⌘G / ⌘⇧G
Next / previous match
⌘R
Refresh the graph
⌘,
Open settings
⌘W
Return from diff; otherwise close the window
⌘Q
Quit the app
